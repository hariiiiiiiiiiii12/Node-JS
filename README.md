# Node.js Learning Journey

## Project: DevTinder (Backend)

During the course a backend project called **DevTinder** was built.

DevTinder is a platform where developers can:

- Create profiles
- Send connection requests
- Accept or reject connection requests
- View connections
- Authenticate securely

The backend includes:

- REST APIs using Express
- MongoDB database
- Mongoose models
- JWT authentication
- Password encryption
- Data validation
